# CS2012 Database Systems — Module Handbook

## 1. Module Information

CS2012 Database Systems is a 20-credit level 5 module taught in Semester 1. The module leader is Dr. Nadeesha Perera, who holds office hours every Wednesday from 14:00 to 16:00. Lectures take place on Mondays and laboratory sessions on Thursdays.

## 2. Learning Outcomes

On successful completion of the module, students will be able to design a normalised relational schema from a set of requirements, write SQL queries that use joins, subqueries and aggregation, implement constraints, views and stored procedures in Microsoft SQL Server, and explain how transactions and indexes affect correctness and performance.

## 3. Teaching Schedule

Weeks 1–3 cover the relational model, entity-relationship modelling and normalization. Weeks 4–6 cover SQL queries, joins and subqueries. Weeks 7–9 cover views, stored procedures, triggers and transactions. Weeks 10–12 cover indexing, query optimization and NoSQL databases.

## 4. Assessment

The module is assessed by coursework (50%) and a final examination (50%). Coursework 1 is an individual ER modelling and normalization exercise worth 15%; it was due on [[-6d]]. The SQL laboratory test is worth 10% and will be held during the laboratory session on [[+17d]]. The group database project is worth 25% and is due on [[+3d]] at 23:59. The project requires each group to design, implement and document a SQL Server database for a real-world scenario, including stored procedures and a short report. The final examination is a two-hour closed-book paper scheduled for [[+71d]].

## 5. Group Project Requirements

Groups of three or four students must submit an ER diagram, a normalised schema, the T-SQL scripts, sample data and a report of no more than 3,000 words. Every member must contribute to the implementation, and each group must submit a peer assessment form with the project. Late group projects follow the standard late submission penalty of 5% per working day.

## 6. Reading List

The essential text is Database System Concepts by Silberschatz, Korth and Sudarshan. Recommended reading includes Fundamentals of Database Systems by Elmasri and Navathe, and the Microsoft SQL Server documentation for T-SQL syntax and examples.
