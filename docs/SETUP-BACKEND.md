# EDU-SMART · Backend Setup (Laravel 11)

REST API powering both the web and mobile clients. Laravel 11 slim skeleton,
Sanctum token auth, MySQL 8.

---

## Requirements

| Tool | Version | Check |
| ---- | ------- | ----- |
| PHP | **8.2+** | `php -v` |
| Composer | 2.x | `composer -V` |
| MySQL | 8.0+ (or MariaDB 10.6+) | `mysql --version` |

PHP extensions required: `pdo_mysql`, `mbstring`, `openssl`, `tokenizer`, `xml`,
`ctype`, `json`, `bcmath`, `fileinfo`.

On Windows the easiest route is [Laragon](https://laragon.org/) or
[XAMPP](https://www.apachefriends.org/) (both bundle PHP + MySQL + Composer).
On macOS: `brew install php composer mysql`.

> **Note:** this repository was authored on a machine without a PHP toolchain, so
> the backend has not been executed here. It is a complete hand-written Laravel 11
> skeleton — the steps below are all that is needed to bring it up.

## Setup

### 1. Install dependencies

```bash
cd backend-laravel
composer install
```

This creates `vendor/` and runs `package:discover`, which registers Sanctum.

### 2. Create the environment file

```bash
cp .env.example .env          # macOS / Linux
copy .env.example .env        # Windows (cmd / PowerShell)
```

Then generate the application key:

```bash
php artisan key:generate
```

### 3. Create the database — pick ONE path

#### Path A — migrations (recommended)

Make sure MySQL is running and `.env` credentials are correct, then:

```bash
php artisan migrate --seed
```

Creates all tables and seeds the demo dataset.

#### Path B — raw SQL

```bash
mysql -u root -p < database/sql/schema.sql
php artisan db:seed
```

> ⚠️ **Never mix the paths.** `schema.sql` leaves the `migrations` table empty, so
> running `php artisan migrate` afterwards fails with *"table already exists"*.
> Details: [`DATABASE.md`](DATABASE.md#provisioning-choose-one-path).

> ⚠️ **Do not run `php artisan install:api`.** Sanctum already ships its own
> `personal_access_tokens` migration; the scaffolding command would add a duplicate
> and rewrite `bootstrap/app.php`.

### 4. Verify storage permissions

The skeleton ships the required writable directories with `.gitignore` placeholders:

```
storage/app/  storage/app/public/  storage/framework/cache/data/
storage/framework/sessions/  storage/framework/testing/  storage/framework/views/
storage/logs/  bootstrap/cache/
```

On Linux/macOS, if you hit permission errors:

```bash
chmod -R 775 storage bootstrap/cache
```

### 5. Start the server

```bash
php artisan serve
# → http://localhost:8000
```

To let a **physical mobile device** reach it:

```bash
php artisan serve --host=0.0.0.0 --port=8000
```

### 6. Smoke test

```bash
curl http://localhost:8000/api/health
```

Expected:

```json
{"status":"ok","service":"edu-smart-api","time":"2026-09-13T09:14:02+00:00"}
```

Full test script (login → dashboard → rank → chat):
[`API.md` § Quick smoke test](API.md#quick-smoke-test).

## Environment variables

`.env.example` ships with working local defaults. The ones you may need to change:

| Variable | Default | Notes |
| -------- | ------- | ----- |
| `APP_KEY` | *(empty)* | **Must** be set via `php artisan key:generate` |
| `APP_DEBUG` | `true` | Set `false` in production |
| `APP_URL` | `http://localhost:8000` | |
| `FRONTEND_URL` | `http://localhost:5173` | Origin allowed by `config/cors.php` |
| `DB_HOST` | `127.0.0.1` | |
| `DB_PORT` | `3306` | |
| `DB_DATABASE` | `edu_smart` | Created by `schema.sql`; by `migrate` otherwise |
| `DB_USERNAME` | `root` | |
| `DB_PASSWORD` | *(empty)* | Set your MySQL password |
| `SANCTUM_STATEFUL_DOMAINS` | `localhost:5173,127.0.0.1:5173,localhost:19006` | Comma-separated, no `http://` |

### Drivers chosen for zero extra tables

| Setting | Value | Why |
| ------- | ----- | --- |
| `CACHE_STORE` | `file` | No `cache` table needed |
| `SESSION_DRIVER` | `file` | No `sessions` table needed — the API is token-based |
| `QUEUE_CONNECTION` | `sync` | No `jobs`/`failed_jobs` tables, no worker process |
| `MAIL_MAILER` | `log` | No SMTP credentials needed to boot |
| `FILESYSTEM_DISK` | `local` | Uploads land in `storage/app/` |

The app therefore boots against **only** the EDU-SMART schema tables.

Re-seed at any time:


## CORS

`config/cors.php` allows `FRONTEND_URL` plus localhost dev origins. If the web or
mobile client is blocked:

```php
'paths' => ['api/*', 'sanctum/csrf-cookie'],
'allowed_origins' => [env('FRONTEND_URL', 'http://localhost:5173')],
'supports_credentials' => true,
```

After editing `.env`, clear the config cache:

```bash
php artisan config:clear
```

Bearer-token clients (both apps here) do **not** need `SANCTUM_STATEFUL_DOMAINS` —
that setting only matters for cookie-based SPA auth.

## Production notes

1. Set `APP_ENV=production` and `APP_DEBUG=false`.
2. Run `php artisan config:cache route:cache view:cache`.
3. Point the web server root at `public/` — **never** at the project root.
4. Restrict `config/cors.php` `allowed_origins` to your real frontend domain.
5. Serve over HTTPS; Sanctum tokens are bearer credentials.
6. Use a real `QUEUE_CONNECTION` and `MAIL_MAILER` if you add background work.
7. Schedule `storage:unlink-old-backups` and prune `personal_access_tokens`.

## Troubleshooting

| Symptom | Fix |
| ------- | --- |
| `Class "PDO" not found` | Enable `extension=pdo_mysql` in `php.ini`, restart PHP |
| `could not find driver` | Same as above — the MySQL PDO driver is missing |
| `Access denied for user 'root'@'localhost'` | Wrong `DB_USERNAME`/`DB_PASSWORD` in `.env` |
| `Unknown database 'edu_smart'` | Run `migrate` (creates it) or import `schema.sql` (creates it) |
| `Base table or view already exists: users` | You mixed both provisioning paths → `php artisan migrate:fresh --seed` |
| `No application encryption key has been specified` | `php artisan key:generate` |
| `Target class [App\Http\Controllers\…] does not exist` | `composer dump-autoload` |
| 404 on every `/api/*` route | `bootstrap/app.php` must register `api: __DIR__.'/../routes/api.php'`; then `php artisan route:list --path=api` |
| `Route [login] not defined` on 401 | Expected for unauthenticated API calls — ensure the client sends `Accept: application/json` so Laravel returns JSON, not a redirect |
| CORS preflight fails | Check `FRONTEND_URL`, then `php artisan config:clear` |
| 419 / CSRF on API calls | API routes are token-based and CSRF-exempt; make sure you are hitting `/api/*` and sending `Authorization: Bearer` |
| Uploads fail | `storage/app/` must be writable; `FILESYSTEM_DISK=local` |
| Blank 500 with no detail | `APP_DEBUG=true`, then read `storage/logs/laravel.log` |
